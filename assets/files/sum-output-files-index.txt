# name construction: the stem follows the input file; -out -> "Add tag to default stem name of output files. This command is useful to avoid overwriting output files when running several instances of the same analysis" (../pyrate-command-reference/references/command-list.md:33-35).
# where files land: -wd -> "Define working directory where all output files will be saved. If not specified, output files will be saved in the same directory as the input file" (command-list.md:22-23); the -plot outputs follow the same rule, "by default these files will be save in the same directory as the input file" (doc's typo kept, references/summarize-results.md:40).
# -tag is NOT a naming command: it selects which files to COMBINE (references/summarize-results.md:53-56 for -plot, references/tutorial-2.md:45-49 for -ginput).
